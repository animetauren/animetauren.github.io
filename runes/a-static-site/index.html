a static site is a promise

HTML and CSS, served as files. No server rendering, no hydration, no JavaScript waiting to be parsed before the first pixel appears.

There's a promise buried in that: the page you save today will still open in ten years. Not because browsers are generous, but because nothing here depends on a build that has to keep working.

I don't think every site should be static. Some things genuinely need a database and a request cycle. But most personal pages don't. A page about a person is, at heart, a document — and documents have been fine for a very long time.

The other half of the promise is maintenance. When this site breaks, it will be because I broke it, in a file I can read from top to bottom in one sitting. That's a nice property to have.
