about

I'm Henry Robalino. I build software — mostly for the web, mostly the kind that loads fast and then gets out of the way.

This page is deliberately plain: HTML and CSS, no framework, no build step, no analytics. What you see is the whole of it. I like that a static file can outlive the tool that made it.

I'm drawn to small tools, good typography, old alphabets, and the quiet corners of the internet. When I'm not building, I'm usually reading about how people used to make things.

You can find me on GitHub and LinkedIn, or read the blog.
