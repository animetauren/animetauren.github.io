about

I'm Henry Robalino. I'm a Senior Industry Technical Strategist for Financial Services at Splunk, where I work with banks, insurers, and other financial institutions on fraud detection, security monitoring, and digital resilience.

Before that I was a solutions architect at AWS, and before that I started at Microsoft on the consulting side, straight out of NJIT, where I studied computer engineering. I've written about some of that work for Splunk Lantern and the AWS Machine Learning blog.

This page is deliberately plain: HTML and CSS, no framework, no build step, no analytics. What you see is the whole of it. I like that a static file can outlive the tool that made it.

I was born in Ecuador and live in the New Jersey area. I'm drawn to small tools, good typography, linguistics, and the quiet corners of the internet.

You can find me on GitHub and LinkedIn, or read the notes.
